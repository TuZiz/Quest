# 第一章 · 星海初醒：任务与奖励对照

本章教学最高要求机器 Lv.2；不限制 Genlite 本身后续升级能力。完成收集器提取资源即完成主线，不再设置独立的空岛信息主线。

**本章发放铜币和银币，不发放金币物品（currency:gold_coin）和金条。** 铜币每枚右键兑换1金币，银币每枚兑换10金币，沿用现有CraftEngine货币配置。 所有下列数量均为当前默认配置，可在任务 YAML 中调整。

## 章节与奖励规则

- 主线全部完成后，章节奖励为：铁片 × 4、铜丝 × 4。支线不影响章节完成和章节奖励。
- 初见引航员属于个人引导；其余任务沿用空岛共享进度。共享任务与章节各只结算一次，不按队员人数重复发放。
- 第一批资源只提供Lv.1→Lv.2所需的2个初级升级单元；移除Lv.3～5阶段及其后续升级材料奖励。
- 资源的归宿完成后奖励普通燃料8个，不再提供升级到Lv.3的6个升级单元。
- 绑定工具与收集器在机械革新完成后提供；不增加可重复领取设备的入口。
- 奖励配置的item旁已注释中文名，物品ID保持不变。

## 升级兼容

- 新版本自动将旧upgrade_three、upgrade_four、upgrade_five、island_scale任务配置及章节引用存入 `.migrations/chapter-one-level-two-v1/` 的迁移前备份，然后退出活动配置。
- SQLite旧任务进度、领奖记录与已生成的奖励包裹不删除、不重发、不追缴。已领取章节奖励的空岛不会再次获得章节奖励。
- 只将旧版资源的归宿默认“6个初级升级单元”替换为新奖励；自定义奖励保留。旧包裹的内容仍按生成时的记录送达。
- 现有GUI、HUD、NPC与资源包不变。本轮仅调整章节范围、任务配置和迁移；前期整体扩展尚未完成的验收仍见根目录TUTORIAL-DEVELOPMENT.md。

## 货币奖励分配

道具与货币二选一：有道具奖励的任务不再给货币，没有道具奖励的任务才补货币。个人NPC引导仍沿用独立引导机制，不新增共享奖励。

| 任务 | 货币奖励 |
|---|---|
| 收集的力量 | 铜币3枚 |
| 机械的联系 | 铜币5枚 |
| 自动化初体验 | 银币1枚 |
| 自由的生产（支线） | 银币1枚 |
| 家园的成长（支线） | 铜币5枚 |

主线货币总计铜币8枚、银币1枚；支线货币总计铜币5枚、银币1枚；全章共铜币13枚、银币2枚，可右键兑换33金币。共享任务只发一份，不按队员数量重复发。

章节奖励铁片4个、铜丝4个，不加货币。其他任务保留原有工具、设备、材料和燃料奖励，不叠加货币。金币物品和金条均不发放。

旧配置通过 `.migrations/chapter-one-reward-choice-v1/` 备份后调整，已有同类货币数量保留。已结算任务不补发，历史奖励包裹不改写。

## RPG奖励约定

当前第一章不发放任何原版物品奖励；圆石等任务目标与GUI图标不是奖励，不受此规则影响。星海启航只发首台原石生成器，移除面包与石镐；资源的归宿只发普通燃料8个；初次试炼奖励普通燃料8个；章节奖励铁片4个与铜丝4个。使用现有CraftEngine注册物品，不新增材质。未来仅在明确的教学需求下单独配置必要的原版物品。

旧配置调整前保存在 `.migrations/chapter-one-rpg-rewards-v1/`，既有完成、领奖及历史包裹不清空、不追缴、不重发。
